# indirect-predicates-gen

Code generator for
[`indirect-predicates`](https://crates.io/crates/indirect-predicates): turns
the definition of a predicate or of a point type into specialized Rust code.

> **Status: early development.** This crate is a placeholder and has no usable
> API yet.
